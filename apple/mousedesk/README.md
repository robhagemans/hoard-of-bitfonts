Mouse Desk and Apple II DeskTop
===============================

Mouse Desk was a GUI for the Apple II, developed by Version Soft. It was later licenced by Apple and rebranded Apple II DeskTop.
See https://www.a2desktop.com/history for more information.

The fonts included here are versions of the Mouse Desk system font:

- Mouse Desk 1.0, also used in version 1.1
- Mouse Desk 1.5, also used in version 1.6
- Mouse Desk 2.0, also used in Apple II DeskTop 1.0 and 1.1
