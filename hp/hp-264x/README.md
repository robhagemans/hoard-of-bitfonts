HP-2640 series
==============

This directory contains ROM character sets from the HP-2640 series of display terminals.

The device and fonts are described at 
- https://www.curiousmarc.com/computing/hp-264x-terminals
See also
- https://terminals-wiki.org/wiki/index.php/HP_2640A
- https://en.wikipedia.org/wiki/HP_2640

A distinguishing feature of this device is that it could display character rows shifted by half a pixel.
To be able to represent this feature, the 8x14 and 9x14 glyphs are recorded here as interlaced double width.
